# Prompts — Arena Agent

Versioned prompts used with Arena Agent for: research organization, strategic
synthesis, content architecture, code generation/iteration, documentation.

## Naming convention

`PH{phase}-{task}.md` — e.g. `PH01-intelligence-research.md`, `PH08-hero-section.md`

## Rules

- One prompt per file, with a short header: goal, phase, expected output.
- Keep the prompt that actually produced approved output (it is project memory).
- Reference — never copy — locked docs (`docs/…`, `content/…`) inside prompts.
