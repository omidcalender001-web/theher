# Prompts — Google AI Studio

Prompts for structured AI-assisted reasoning: content systems, generation
experiments (copy variants, transcreation passes), development assistance,
workflow experimentation.

## Naming convention

`PH{phase}-{task}.md` — e.g. `PH03-transcreation-pass-1.md`

## Rules

- Store the system instruction + the key user prompt per experiment.
- Record what was accepted vs rejected (small log at the bottom of each file).
