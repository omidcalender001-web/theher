# Images (web-optimized stills, textures, posters)

## Specs (Phase 06 output)

- Format: WebP (AVIF optional bonus) + JPG fallback where needed
- Widths (srcset): 640 / 1024 / 1600 / 2400 px
- Per-file target: ≤ 300 KB
- Naming: `scene-{nn}-{slug}-{width}.webp` (e.g. `scene-01-vision-1600.webp`)

## Folders

- `posters/` — one poster frame per video (also used as mobile fallback)
- `stills/` — editorial stills from Flow scenes
- `textures/` — ivory/champagne grain, paper, light-leak backgrounds

Raw originals from Flow keep their export names; optimized copies go here.
