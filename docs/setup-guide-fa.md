## ۲) تصمیم‌های معماری فنی (چرا این استک؟)

| لایه | انتخاب | دلیل |
|---|---|---|
| فریم‌ورک | **Astro** (خروجی استاتیک) | صفر-JS پیش‌فرض → سرعت بالا، i18n داخلی، کامپوننت‌محور، بیلد خودکار روی Netlify؛ حس «ادیتوریال» با HTML/CSS تمیز |
| انیمیشن اسکرول | **GSAP + ScrollTrigger** | استاندارد صنعتی برای تجربه‌های scroll-cinematic؛ پشتیبانی `prefers-reduced-motion` |
| استایل | **CSS خام + Design Tokens** (متغیر) | کنترل دقیق تایپوگرافی ادیتوریال؛ Tailwind برای این پروژه حس SaaS می‌داد |
| دوزبانگی | دیکشنری JSON (`src/i18n/en.json` و `fa.json`) + سوییچ زبان + `dir="rtl"` | حفظ جایگاه روایی هنگام تعویض زبان |
| فونت فارسی | **Vazirmatn** (متن‌باز، OFL) | تنها فونت فارسی باکیفیت که با لحن Quiet Luxury جور درمی‌آید |
| فونت انگلیسی | Serif ادیتوریال (Cormorant Garamond / Marcellus) + Sans سبک | تیترهای بزرگ ادیتوریال با وزن نازک |
| آنالیتیکس | GA4 (یا Plausible) | ایونت‌های: page_view, language_switch, cta_click, case_interaction, scroll_depth, contact_initiation |
| هاست/دیپلوی | **Netlify** متصل به GitHub | پوش کن → بیلد و دیپلوی خودکار؛ `netlify.toml` همین‌جا ست شده |

**مسیر جایگزین (ساده‌تر):** HTML/CSS/JS خالص بدون بیلد — فقط اگر بخواهید از npm و Node
دوری کنید. برای این پروژه Astro توصیه می‌شود چون کامپوننت‌ها و i18n را ساختارمند می‌کند.

## ۴) مشخصات فنی دارایی‌ها (الزامات مهندسی)

### ویدیو (خروجی Google Flow)
- **MP4 · H.264 · 1080p · 24fps · 6–10 ثانیه · لوپ بی‌درز · ≤ 8MB بر صحنه** (+ نسخه موبایل 720p ≤ 4MB)
- **پوستر JPG برای هر ویدیو** (fallback موبایل + reduced-motion + سرعت)
- `preload="metadata"`, `muted`, `playsinline`, لود با IntersectionObserver
- ⚠️ **گیت‌هاب فایل بالای 100MB را رد می‌کند** — فایل خام سنگین را در Drive نگه دارید و فقط نسخه وب را کامیت کنید (دستور ffmpeg در `assets/video/README.md`)

### تصویر
- WebP (و AVIF) با عرض‌های 640/1024/1600/2400 و `srcset` — هر فایل ≤ 300KB

### فونت
- WOFF2 ساب‌ست‌شده و self-host (پرفورمنس + RTL صحیح) — فارسی: Vazirmatn

### کد
- HTML معنایی · ویژگی‌های منطقی CSS (`margin-inline` …) برای RTL خودکار ·
  `prefers-reduced-motion` · حداقل JS بلاک‌کننده · بدون انیمیشن بی‌دلیل

## ۷) دیپلوی روی Netlify (فاز ۱۰)

1. در Netlify: **Add new site → Import from GitHub** → انتخاب ریپو
2. Build command: `npm run build` · Publish: `dist` (در `netlify.toml` ست شده)
3. فعال‌سازی پیش‌نمایش Deploy Preview برای هر PR
4. اتصال دامنه (در صورت نیاز) + تأیید HTTPS
5. بررسی ایونت‌های آنالیتیکس روی URL لایو
